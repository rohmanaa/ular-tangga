## 4.1.15.1 Audit (hasil)
### File diperiksa
`game/gameplay.html`, `game/gameplay/{module-bridge,feedback,audio,hud}.js`, `game/assets/js/game-integration.js`, `game/mode.html`, `game/loading.html`.

### Flow existing
- Game Room (`lobby.html`) -> `mode.html` -> `loading.html?to=gameplay` -> `gameplay.html`. `game-integration.js` menormalkan `ut-config` (mode, skins, theme, dice). Mode: `cpu` (Player vs Computer/Villager), `2`/`3`/`4` (pass-and-play satu perangkat, semua pemain manusia).
- `gameplay.html` baris akhir memanggil `startGame(CFG.mode, CFG.skins)`; tombol \"Main lagi\" memanggil `startGame(mode,lastSkins)`.
- State giliran = `players[]` + `cur` (indeks). `nextTurn(){cur=(cur+1)%players.length; busy=false; beginTurn()}`. Tidak ada turn manager terpisah.
- `p.idx` = slot kayu api unggun/offset petak (`slotPos(p.idx,...)`), BUKAN urutan giliran. Urutan giliran = posisi di `players[]`.
- Roll: `#btnRoll` -> `doRoll()` (guard `busy||paused||gameOver`). CPU: `beginTurn` menjadwalkan `doRoll` sendiri (setTimeout 950 ms, memakai `gameId` sebagai guard stale).
- Power: `usePU(k)` instan, tanpa modal target/konfirmasi (TNT/Grass memilih target otomatis = pemain terdepan). Kartu Chest (`#puCard`) hilang otomatis. Menu jeda: flag `paused`. Layar menang: `#win`.
- State yang menunggu input manusia: HANYA tombol Roll (dan Power opsional yang tidak memblokir). Modal target/konfirmasi/pilihan chest belum ada -> mekanisme fallback generik disiapkan untuk masa depan.

### Titik integrasi
- Ready+Shuffle disisipkan di `startGame()` setelah pawn dibuat dan sebelum `beginTurn()`.
- Shuffle = mengurutkan ulang `players[]` (pakai ulang `cur`/`nextTurn`), `p.idx` tidak diubah. Tidak ada turn manager kedua.
- Timer: modul baru `gameplay/afk.js` (`UT.GameplayAFK`), satu timer aktif per id. Ready Screen: `gameplay/ready.js` (`UT.GameplayReady`). Wajah pemain memakai `faceURL()` existing (tanpa renderer baru).

### Risiko / regression
- `startGame` dipanggil ulang saat restart -> Ready harus dibatalkan/dibersihkan (guard `gameId`).
- `paused` (menu jeda) harus menghentikan timer AFK; CPU `go()` sudah menunggu `paused`.
- Wajah PNG baru tersedia setelah texture termuat (`loadSkin3D`) -> tunggu singkat sebelum menampilkan kartu.
- Jangan menyentuh audio (4.1.14.10) dan skin/Villager (4.1.14.10).
- `?ready=0` disediakan untuk melewati Ready (uji/backward-compat).
