- Reset: `resetCam()` (tombol `#btnCam` "Reset Kamera", juga dipanggil `startGame` dan keluar dari `togglePov`). `togglePov` = POV Atas (top-down murni, pitch ~1.52).

## Keputusan desain
- Tidak ada camera engine kedua. `resetCam(P)` diperluas menerima preset; tanpa argumen memakai preset aktif (ANGLE ON) atau default lama (OFF).
- ANGLE OFF = perilaku lama TIDAK berubah (follow selalu aktif, interaksi tetap aktif). LOCK sengaja ditunda ke Part 2.
- Tombol existing `#btnCam` dipakai sebagai RESET: label "Reset", hanya tampil saat ANGLE ON (sesuai spesifikasi). Konsekuensi: saat ANGLE OFF tombol "Reset Kamera" lama tidak tampil.
- Preset hanya titik awal: manual drag/rotate/zoom tetap bebas dan dropdown tidak berubah; Reset kembali ke preset aktif. Memilih "Free Camera" tidak memindahkan kamera; Reset pada Free = sudut default.
- FOLLOW OFF membekukan titik pandang saat dimatikan (tanpa loncat) lewat `camHold`; Reset mengembalikan titik pandang ke tengah papan.
- Persistence: `localStorage['ut-cam']` = `{angle,preset,follow}`. ANGLE OFF tidak menghapus preset/follow; ANGLE ON lagi menerapkan preset terakhir.
- UI: tombol ANGLE di toolbar; saat ON, baris sendiri di bawah toolbar berisi dropdown preset (`<select>`), FOLLOW, RESET (class `body.cam-angle`). Versi satu baris tunggal membuat toolbar terpotong di landscape/tablet, jadi dipisah.
